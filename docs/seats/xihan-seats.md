# 西汉席位试跑

规则见 pipeline/PLAYBOOK.md。汉代专题这一轮从 34 人增至 40 人。全览能看见新入册的人。叙事章仍是各自点名。

高帝到孺子婴的帝系原来已经在册，这一轮不改他们的生卒。只补《汉书·外戚传》里能钉住崩年、又是在位皇后或掌权太后的人。吕后、窦漪房、卫子夫、王政君原来已经在册。

100 到 160 的检查线还没有达到。没有为了凑数放宽席位。

张皇后是鲁元公主的女儿，不是吕后的侄女。惠帝崩后废处北宫。

上官皇后在宣帝时已经是太皇太后，建昭二年才崩。邛成太后只写年七十余，不编生年。

## 这一轮不收

- 赵飞燕：哀帝崩后月余废为庶人，是日自杀。传文没有写出废黜的那一年。
- 孝宣许皇后：立三年而崩，没有年号。霍皇后自杀前只写徙馆后十二岁，也没有年号。
- 陈皇后、钩弋赵婕妤、李夫人：传里没有钉住崩年。
- 窦漪房：现有登记据《史记·外戚世家》，卒年是公元前135年。《汉书》写元光六年崩。两书不一致，这一轮不改旧登记。

## 还没跑的席位

- 少帝刘恭、刘弘在吕后纪里在位，这一轮没有单独抽出卒年。
- 宰相：霍光、桑弘羊、公孙弘已经在册。没有卒年的三公不补。
