# 明朝席位试跑

规则见 `pipeline/PLAYBOOK.md`。明朝专题现为 132 人：明朝籍 125 人，另从元册复用陈友谅、张士诚，从清册复用努尔哈赤、皇太极、多尔衮，蒙古势力复用也先、俺答汗。全览能看见所有 132 人；叙事章各自点名。

时间窗一三六〇年放宽到一六八〇年（原止 1660），理由是宋应星（卒 1666）与吴三桂（卒 1678）本已在册而原来出窗；放宽后不再改收黄宗羲（1695）、顾炎武（1682）、王夫之（1692）、张岱（1689）一类。

这一轮补的是被席位点到、而原先没有的人。有几条说明：

- 《明史》纪、传的卒年多数明确，所以这一批人里生卒两端都可定的接近九成。
- 不载于《明史》列传的人物（李贽、徐霞客），另据其著述与墓志，年份只能写到 `approx` 并注明依据。
- 也先之死只在《明史》瓦剌传里说“为其下所攻”，年份诸家不一，写 `disputed` 并出 `deathNote`。
- 建文忠臣、靖难诸将，按其是否占到一个结构席位来取舍，不作全録。
