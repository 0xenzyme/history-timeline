# 宋朝席位试跑与落库

规则见 `pipeline/PLAYBOOK.md`。试跑时底册 40 人，按席位规则可达约 235；已按名单落库，**底册现为 228 人**（188 新登记 + 2 人复用既有登记），本文记试跑方法、逐席结果与落库口径。

## 方法

- 史源：`raw/宋/宋史` 全 502 卷。宰辅席用宰辅表五卷（卷 211–214 有「公元｜纪年｜拜罢｜在任名单」表格；卷 210 建隆—天圣段表格在提取时丢失，该段 20 相手工补录）；其余席位以列传卒句为准（卒/薨/崩＋享年、年份紧邻卒句、自縊/赴海/溺死等形态），年号锚点在卒句前 150–400 字内即可。
- 宰相任期按「拜相到罢免或去世跨三个年头及以上」（加粗在任名单 ∪ 拜相句解析），卒年门槛按「传有卒薨享年句，或宰辅表任上薨卒」执行——宋史列传卒句密度高，卒年门槛几乎不筛人，筛人的是席位定义本身。
- 辽金元人物卒年引各正史（`raw/辽`、`raw/金`、`raw/元`）。
