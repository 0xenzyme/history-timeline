# 隋朝席位试跑

规则见 `pipeline/PLAYBOOK.md`。隋朝底册现为 23 人（原先 15 人）。全览能看见新入册的人；叙事章仍是各自点名，没有把底册铺进章节。

年份只认《隋书》同一篇纪或传里能指到的卒年、薨年或被杀之年。列传写明死于某事，本纪又在有年号的段落里点到这个人，可以采用。只写「江都之难」「化及作乱」而本纪没有点名的，不把两处拼成某一年。只有岁数、没有年份的，不编生年。由卒年与虚岁上推的生年写 `approx`，并在 `birthNote` 里写明。

帝系原来的文帝、炀帝、恭帝没有改。新增后妃、对立两条泳道。牛弘入文臣泳道，席位是礼乐和五礼，不是宰相。关系补到能说明废立、平陈、辽东、突厥和杨昭父子，不把同时代写成边。

50–80 的检查线仍未达到。这一轮没有为了凑数放宽席位。

## 占了席位但这一次没有入册

- 萧皇后：炀帝皇后。传写宇文化及之乱后没于窦建德，贞观四年归京师，没有崩年。
- 宣华夫人、容华夫人：废立时在场。传没有卒年。
- 苏威：尚书右仆射、纳言，秦王称他为隋朝宰辅，任期远超过三年。传只写归长安后卒于家，时年八十二，没有年份。
- 杨侗：皇泰称帝，是实际称帝者。传写仰药、帛缢，没有年份，不编成 619。
- 来护儿：三征高句丽的水军主将。传只写江都之难为宇文化及所害。本纪记义宁二年三月之变，没有点他的名，不拼年份。
- 杨谅：高祖崩后起兵，传写幽死，没有年份。
- 杨暕：储位当事人。化及斩之，时年三十四，句中没有年号。
- 杨秀：化及害之，没有年份。
- 杨俊：传从开皇元年数到二十年六月薨，年份能钉住，但只是奢纵而卒，没有进入储位之争或起兵，不占宗室席位。
- 高元：三征的另一方。高丽传写到征召不至，没有卒年。
- 薛道衡：文学席位在。传写缢杀，时年七十，没有年份。
- 虞世基、裴蕴：大业权臣，死于江都之变。传没有把卒年写成某一年。
- 裴矩：传写到归唐授民部尚书，篇内没有卒年。

## 有待复核

宰相席位还没有一张像唐朝宰相表那样的任期表。苏威的卒年若在他书里能钉到某一年，下一轮再收。来护儿、杨侗、杨谅也一样：先有年份，再决定是否入册。

## 代周的另一方

南北朝本纪对读时，周静帝的卒年写在《周书》静帝纪里：开皇元年五月崩，年九岁。大定元年杨坚称帝，他逊于别宫。此人并入隋全览，挂在「杨坚代周」上。生年用建德二年，不在隋的席位表里重复计生卒。
