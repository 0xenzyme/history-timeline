3. 每条候选都回 `raw/` 原文取证。本次对全部候选行做了脚本核验：`anchor_quote` 必须是指定 `raw/...:行号` 那一行的逐字子串（忽略空格）。**共 339 行，0 行失配**（3 处引文的标点经修正后通过）。
4. 去重按姓名与 id 双向对照 `content/*/*.md` 与 `pipeline/registry/people/*.json`（合计 2601 个 id）。跨片重复已合并；与既有 id 冲突者加后缀（如 `zhao-kuo-jin` 避开长平赵括 `zhao-kuo`）。
5. 本文件只做研究。未改动 `content/`、`pipeline/`、`public/`、`src/` 任何文件，未 commit。
6. 未使用 Wikidata／CBDB 数字当锚点。

## 不收与需外证的理由

本节的「需外证」指：raw 锚点缺失，或席位证据缺一环（原文只给相对年数、只一见而无独立职务／战事、身份或归属待专题口径厘定）。「不收」指：席位不成立（无名、无年、无传世作品、非卿非将）、出专题窗口、或已在别的专题收录。
