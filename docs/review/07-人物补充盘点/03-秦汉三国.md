# 西汉、东汉、三国专题人物收录缺口审计

审计范围：`han`（西汉）、`donghan`（东汉）、`sanguo`（三国）。口径见 `pipeline/PLAYBOOK.md`：占到结构席位，且有可引用的年份锚点（`exact` / `approx` / `disputed`）。缺口指：按席位定义应该收、年份锚点能在 `raw/` 原文引到、但 `content/` 里还没有的人。

锚点一律回 `raw/` 原文核对，给出原文片段与文件行号。数据库数字（Wikidata、CBDB）不作锚点。只有活动年、任官年的按 `approx` 收，note 写明「活动年，非寿数」。生卒有异说的写 `disputed`。同一人只有一份文件，跨专题共用，按姓名与 id 双向去重（如窦婴已在 `content/han/dou-ying.md`、田横已在 `content/qin/tian-heng.md`，本报告不再登记）。

## 不收与需外证的理由

### han（西汉）

- **需外证（占席但缺年份）**：少帝刘恭（高后四年幽于永巷，「幽杀」无年）；卢绾（亡入匈奴后卒年不明，后汉书/汉书均无年）；王陵、卫绾、陶青、刘舍、许昌、薛泽、张欧、彭宣、马宫、薛广德（占丞相/御史大夫席，任期跨年，但卒句无年号，本纪与百官公卿表也不给卒年）。
- **不收（无对应席位或无年份）**：江充、石显、邓通、韩嫣（佞幸，席位表无佞幸席）；李延年（传文「上遂誅延年兄弟宗族」无年号，且无传世乐谱，不占文学艺术席）；东方朔、陆贾、叔孙通、枚皋、王褒、夏侯胜、苏建、赵破奴、程不识、李息（占席候选，但 raw/汉书 与通鉴均不给可引年份）；陈皇后、李夫人、班婕妤、栗姬（传文无崩年/卒年号，非实际皇后或掌权后妃）。
- **已收，勿重复**：窦婴（content/han/dou-ying.md）、田横（content/qin/tian-heng.md）已在册；冯奉世、周亚夫等未见任何专题文件，可新收。
- **老上单于**锚点行内带整理者括注（前158），PLAYBOOK 要求以正文纪年为准；正文只作「後四年」，入库前需另据文帝纪/匈奴传前后文复核。
