### 5. 本次自建的席位口径

`rujia` 专题没有 `docs/seats/rujia-seats.md`。按 `PLAYBOOK.md`「谁进专题」一节（占一个结构席位 + 有可引用的年份锚点，`exact` / `approx` / `disputed` 三态均可），本报告为 `rujia` 自建三席，席位只判资格，不设人数上限：

- **S1 传道（师承）**：孔门亲炙弟子，以及孔子卒后在儒门师承链上被《史记》专门立项的人。锚点常为**活动年／事件年**，`approx`，note 必须写「活动下限／上限，非寿数」。
- **S2 传经（经学）**：两汉五经博士系统里「某经之学的开创者或立于学官的一家」的代表，以及今古文之争的主要人物。锚点为授受、任官、论石渠等系年。
- **S3 传学（理学 · 考据）**：宋元明理学／心学的开山、集大成与他人所承的主要弟子，以及清代考据学的开创者与代表人物。锚点多为生卒年（`exact` 或 `approx`），须有传世著作。

**席位与 lane 的对应**：本专题 `lanes[]` 只定义了 `ru`、`fa` 两条。S1／S2／S3 在 `rujia` 里一律映射到 lane **`ru`**；超出 `rujia` 声明范围（前 90 年之后）的人，席位落在其朝代专题的既有 lane 上（`han`/`donghan` 的 `scholar`，`song`/`yuan`/`ming`/`qing` 的 `literati`）。

### 6. 「归属」的判定口径（本报告使用的定义）

按 `PLAYBOOK.md`「有朝代专题时不放进 rujia」与「同一条登记可出现在多个专题，只改 lane 与文案」：

- **「新建 rujia 登记」** = 该候选的年份锚点落在 `rujia` 声明的 `range[−560,−90]` 内，应当**新增一条 `rujia` 收录**（`topic.json` 的 `people[]` 追加 `{id, lane:"ru"}`，并先走 `candidates.json` 的 `pending` 流程）。其 canonical 文件仍按 `polity` 落在朝代目录（如前 200 年的叔孙通落 `content/han/`），不在 rujia 目录另建一份。
- **「只在朝代专题内加 lane」** = 该候选的年份锚点**晚于前 90 年**，超出 `rujia` 的 `range` 与 `eras`，因此不进 rujia 底册；只在所属朝代专题里新增 lane 覆盖。若维护者要把 `rujia` 的下限推到「两汉」或更晚，那是**修改 `meta.range` / `catalog.eras` / 副标题的范围决策**，本报告不单方面执行。
