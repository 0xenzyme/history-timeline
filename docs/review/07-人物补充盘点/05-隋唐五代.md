# 隋 · 唐 · 五代十国 收录缺口研究

研究对象：`sui`（隋）、`tang`（唐）、`wudai`（五代十国）三个专题。目标：找出**按《pipeline/PLAYBOOK.md》席位规则应该收、且年份锚点在 `raw/` 史料里可引，但 `content/` 里还没有**的人。

口径与做法：

- 席位按 PLAYBOOK：帝王（标准序列含实际称帝者）、宰相（任相跨三个年头及以上或主持过已上轴的制度/战事）、将帅（已画战事双方主将、改变版图或藩镇格局者）、后妃·外戚、宗室（入储位之争/起兵/实际出镇）、文学·艺术·宗教·技艺（有传世作品且有年份锚点）、对立面（叛首、割据始祖、与外族交兵改变版图者）。不设人数上限。
- 每条候选都回到 `raw/` 原文核实：锚点列给出**逐字照抄的原文片段**（繁体、异体字保持原样）、`raw/.../卷NN.md:行号` 与卷篇名。年份若在紧邻的年号行/年格行，另注「年见」。追不到年份的一律判「需外证」并写明缺什么。
- 生卒：`exact | approx | disputed | unknown`。有异说写两说；只有活动年/任官年的写 `approx` 并注「活动年，非寿数」，不得读成寿数。Wikidata/CBDB 数字不作锚点。
- polity：唐专题收隋臣唐将（如裴矩）时仅标 `tang`，不标 `sui`。
- id 为稳定 kebab-case ASCII；与 `content/**/<id>.md` 冲突时加生卒年后缀（如 `li-wei-tang`）。
- 本文件只登记缺口候选，未改动 `content/`、`pipeline/`、`public/`、`src/`。

判定三档：**可直接入册**（年份锚点已在 raw 追到）、**需外证**（席位成立但 raw 无年份句，须另据他书）、**不收**（不符席位定义或无任何可系年年份）。
