# 界面审查

审查日期 2026-09-26；未在浏览器中操作，结论来自源码

## 结论

主路径是通的。空地址会进入目录第一项「西周」的第一个非总览章「国人与共和」；换章、缩放、拖动和搜索与现在的产品说法大体一致，总览也不会自动打开人物卡。顶栏能看出专题和章节，地址也能回到某一章。

缺口在读图，不在按按钮。缺生年或卒年的人被收成菱形，设计里的固定像素开放条没有画出来，寿命无法和实心条比较。宽屏图例被折进一个看不见的控件，桌面上没有泳道色和关系线型的说明。导出的是整章主图，年份数字却在另一张钉住的轴上，图上没有刻度。深链只到章节，人物和缩放一刷新就丢；读屏还把整张图当成一张图片。

## 界面结构

顶栏是 `index.html` 的 `header.topbar`。专题名和下拉由 `src/ui/topics.ts` 画，可按地区、朝代、主题筛选。章节条是 `src/ui/chapters.ts`。搜索在 `src/ui/search.ts`。缩小、放大、「显示全部关系」、复位、导出的按钮写在 HTML 里，点击在 `src/main.ts`，文件在 `src/export.ts`。关系全景时，带 `timeline-only` 的按钮隐藏，只留「返回时间轴」和导出。

简介条 `.briefbar` 左边是本章 `brief`，右边是操作提示。HTML 初值仍是旧说法（滚轮缩放、Shift / Alt 滚动），`renderChrome` 会改成「滚轮翻人名、Ctrl 或 ⌘ 缩放」；触控或窄屏再换成滑动文案。

`#route-miss` 平时隐藏，由 `renderRouteMiss` 填写。

工作区是 `main.workspace`。`section#stage` 可滚动，里面是钉住的年份轴 `#axis-pin`（`src/timeline/axis.ts` 的 `renderPinnedAxis`，`position: sticky`）和主图 `svg#chart`。时间轴图层在 `renderTimeline`：事件带、泳道、网格、关系、命中区、人物条、事件线与标签、左侧人名，分属 `src/timeline/`。关系全景换成 `src/ui/graph.ts`，仍画在同一张 svg 上。右侧 `aside#card`（`src/ui/card.ts`）没选人就隐藏；窄于 640px 时改成贴底浮层，最高约四成视口。页脚图例来自 `src/ui/legend.ts`。tooltip 和给读屏的 `#status` 不占布局。

人名、事件名、轴上年份、关系图节点都是 SVG `<text>`，不是转曲。

设计文档第 5 节已落后于代码。

- 文档写滚轮即缩放、Shift / Alt 才上下滚。实现和运行后的提示与此相反。
- 文档写点击空白会隐藏全部关系。代码只取消焦点，不改变开关状态。
- 文档写关系线从生年早的人弯向生年晚的人。`relations.ts` 只按人物在画面中的上下位置决定方向，跨泳道时不等于生年先后。
- 文档第 4.3 节写事件标签最多 4 行。`events.ts` 的 `LABEL_ROWS` 是 3。

## 问题

1. **高**。只有生年或只有卒年的人变成菱形，未知一侧只是大约 5 像素的开口折线，不是固定像素的开放条。读者会把「生年不详、人却活了几十年」看成一个时间点。图例写「一端不详」配菱形，设计文档 3.2 仍要求 56px 开放条。三处说法不一致。见 `geometry.ts` 的 `barGeom`、`bars.ts`、`legend.ts`。

2. **高**。页脚用未加 `open` 的 `details` 包住图例，宽屏又把 `summary` 设成 `display: none`。按 HTML 对未打开 `details` 的默认样式，图例正文会被隐藏，而且没有可见的「图例」可点。窄于 640px 时标题才出现，折叠才用得上。桌面上看不到泳道色、关系线型和「确切 / 约略 / 一端不详」。见 `index.html` 页脚，`styles.css` 的 `.legend-summary`。未在浏览器里点过，这是级联推断。

3. **高**。导出只序列化 `#chart`。年份数字在 `#axis-pin-svg` 上，PNG 和 SVG 有网格、没有年份。导出的是整章高度加当前时间窗，不是滚过之后屏幕里那一段。设计文档第 5 节写的是「当前视野」。见 `export.ts` 的 `downloadChart`、`axis.ts`。

4. **中**。地址只有 `#专题/章节`。选中的人、缩放到的年份、搜索词、是否在关系全景，刷新或把链接发给别人都会丢。宽屏再进该章会打开数据里的预设焦点（武帝章会打开刘彻），不一定是刚才搜到的人；窄屏则谁也不选。见 `routing.ts` 的 `formatHash`，`main.ts` 的 `initialFocus`、`revealPerson`。

5. **中**。单段未知地址（`#wudi` 除外）被当成西周的章。恢复条写「西周没有『某词』这一章」，并列出西周各章。用户若打错的是专题名，会被带去看错的内容。两段且专题名不存在时，文案才是「没有这个专题」，下面却已经是西周的入口章，按钮仍写「回到西周」。见 `routing.ts` 末段，`renderRouteMiss`。

6. **中**。本专题没有、全库索引也没有时，下拉只留「汉代没有『某某』」这种句子，不说别处也没有，也不再用「没有匹配的人物」。占位「搜索本专题人物」可以接受，话说半句不行。索引未返回时的「正在查找其他专题」是清楚的。见 `search.ts` 的 `buildSearchRows`、`renderSearchResults`。

7. **中**。主图 `role="img"`，里面却是每人一个 `tabindex="0"` 的按钮。读屏往往只把它当成一张图，键盘却要按过每一个人才能到人物卡。按钮的无障碍名是「刘邦，-256至-195」这种原始数字。焦点移出图后没有 `focusout`，`hoverId` 不清，高亮留在最后一行。左侧人名是真文本，但标了 `aria-hidden`。见 `index.html` 的 svg，`bars.ts` 的 `renderHitAreas`，`lanes.ts`，`main.ts` 的 `focusin`。

8. **中**。泳道标题的字色就是泳道色。后妃、外戚一类的 `#c98a3a` 铺在 `#faf7f2` 上，按相对亮度大约 2.7:1，11px 粗体不够读；多数深色泳道大约 4.6:1 到 7:1。放不下的事件只在右上角写 `+N`（`#93866f`，约 10.5px），大约 3.1:1 到 3.3:1。君臣和师承都是实线，只靠颜色分开；同僚、敌对才有不同虚线。宽屏图例又不可见。以上是色值估算，没有用仪器测屏幕。见 `lanes.ts`，`styles.css` 的 `.event-more`，汉代 `relationTypes`。

9. **中**。视口窄于 900px 时章节改成横滑，代码没有把当前章滚进视野。深链打开靠后的章时，顶上的当前章可能在滚动范围外面。见 `styles.css` 的 900px 查询，`chapters.ts` 只替换 HTML。

10. **低**。部分界面文案不够直接。

- 关系按钮禁用时写「还没有录入关系」。“录入”属于编辑语境。
- `+3` 没有说明被隐藏的是事件。
- 图上没有区分异说和约略。图例也没有说明异说。
- 卡片把异说显示为「约」，再附加「有异说」说明。
- 数据加载失败时，画布显示校验器原文。

见 `card.ts`、`format.ts` 的 `MARK` 和 `loader.ts`。

## 建议

1. 宽屏不要把图例藏进看不见的折叠。泳道色和关系线型现在没有第二处说明。
2. 「缺一年怎么画」只留一种说法：要么画出不随缩放变长的开放端，要么在图例和简介里写明菱形只是一个年份点，不要和文档里的 56px 开放条各说各话。
3. 导出带上年份刻度，并按当前看得到的范围来，而不是整章一张没有数字的长图。
4. 链接可以继续只表示章节，但刷新不要用预设焦点冒充刚才选的人；认不出的单段地址按「没有这个专题」提示。
5. 主图不要用 `role="img"` 包住按钮；读屏名字改成「公元前 / 不详」。全库都没有时，把这句话说完。
