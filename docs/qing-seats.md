# 清朝席位试跑

规则见 `pipeline/PLAYBOOK.md`。清朝底册现为 57 人（原先 39 人）。全览能看见新入册的人；叙事章仍是各自点名，没有把底册铺进章节。

年份只认《清史稿》本纪、列传里能指到的卒年或薨年。只有岁数、没有年份的，不编生年。由卒年与虚岁上推的生年写 `approx`，并在 `birthNote` 里写明。传文没有钉住年份的，这一轮不入册。

## 占了席位但这一次没有入册

- 孝慈高皇后：岁癸卯崩，在专题时间窗 1610 年之前，出窗不收。
- 阿桂：传在，本轮没有从卒句钉住年份。
- 穆彰阿、肃顺：政争席位在，卒年或伏法之年没有和年号钉在同一句里，先不写。
- 僧格林沁、胡林翼、丁汝昌：轴上战争的主将。丁汝昌传写威海饮药死，同段没有写年号，先不编年份。
- 杨秀清、石达开、李秀成：太平天国席位在。洪秀全传里没有把他们的卒年钉成某一年，这一轮不收。
- 耿精忠：三藩当事人。传文这一轮没有单独钉住伏法之年。

## 有待复核

《清史稿》没有一张像《明史》宰辅年表那样集中的军机大臣年表。下一轮应先把乾隆以后军机大臣里任期跨三个年头的人与列传卒句对读，再决定是否补阿桂、兆惠、和珅以外的人。和珅已经在册。
