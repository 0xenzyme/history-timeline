# 战国席位试跑

规则见 pipeline/PLAYBOOK.md。战国专题这一轮从 31 人增至 37 人。全览能看见新入册的人。叙事章仍是各自点名，没有把底册铺进章节。

秦君从献公到嬴政原来已经连成一列，这一轮不改他们的生卒，也不把六国国王按世系补全。只补本纪、世家或列传里能钉住卒年，又占太后、宰相或已画战争主将席位的人。

100 到 160 的检查线还没有达到。没有为了凑数放宽席位。

年份都从专题里已经使用的锚年推出，写在各人的 deathNote 里。

- 昭襄王五十六年是前 251 年，所以四十二年是前 265 年，四十七年是前 260 年。
- 赵世家写孝成王二十年秦王政初立。秦王政元年是前 246 年，所以孝成王十五年是前 251 年。
- 魏世家写安釐王三十一年秦王政初立，三十四年信陵君卒，所以是前 243 年。次年景湣王元年秦置东郡，与秦本纪始皇五年初置东郡相同。
- 孝成王二十一年卒，悼襄王九年卒，子迁立。王迁七年因此是前 229 年。
- 春申君列传写死的那年是始皇九年，即前 238 年。他为楚相二十余年。

长平之战补上赵括。邯郸之围补上平原君、信陵君。灭赵的事件补上李牧。事件的年份不改。

- 秦君：嬴师隰、嬴渠梁、嬴驷、嬴荡、嬴稷、嬴柱、嬴子楚、嬴政。

- 变法、战争和诸子：商鞅、吕不韦、孙膑、庞涓、白起、廉颇、乐毅、田单、王翦、张仪、苏秦、蔺相如、孟子、屈原、荀子、韩非。

## 这一轮不收

- 孟尝君：列传只写齐襄王初立之后「文卒」，没有年份。
- 穰侯：秦本纪写四十二年九月出之陶。列传只说后来卒于陶，没有卒年。
- 范雎：列传没有钉住卒年。蔡泽的「卒事始皇帝」不是范雎的卒年。
- 魏安釐王：与信陵君同一句里卒于三十四年。这一轮不把六国国王按世系补进去。楚考烈王也死在始皇九年，同样不补。
- 赵奢：长平开打时列传已说他死了，没有年份。
- 廉颇、乐毅、田单、王翦、蔺相如、孙膑：旧登记是约年或有争议，这一轮不改。
- 信陵君列传本身只说病酒而卒。年份用的是魏世家，不用东郡的旁证另编一个整数。

## 还没跑的席位

- 三家分晋挂在轴上，但魏文侯、赵烈侯、韩景侯的卒年还没有逐句对到前 403 年前后。
- 韩、魏、燕、齐的其余国王，和没有画上轴的战争主将，这一轮不按表补。
- 诸子里庄子、墨子没有本传可钉的卒年。
