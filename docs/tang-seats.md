# 唐朝席位试跑

规则见 `pipeline/PLAYBOOK.md`。唐朝底册现为 171 人。打开「唐全览」能看见；各叙事章仍只放原来的出场名单。

年份只认列传里能指到的卒年或赐死之年。只有岁数、只写「永徽中」「未几」「岁余」，或世系表上的名字，不算可补。宰相表只记任免，任期按拜相到罢免或去世计算，中间空年仍算在任。使相出镇、寻卒而无其年，不收。

## 结果

底册 171 人：原先 72，加后妃宗室将帅藩镇外族 20，加第一批宰相 22，再加这一次核对写入的 54 人，并把已有登记的李密、窦建德、王世充并进唐全览。

200–300 的检查线仍未达到。宰相席位已按任期加卒年跑过；后妃按每位皇帝一位补了有年份的人；将帅和对立面补了轴上已有战事里还缺的主将；文学只补了书法里能定年的虞世南。宗室起兵、其余藩镇创始人、吴道子一类无传或无年份的人，这一次没有写成登记。

## 占了席位、这轮没有年份

传在，卒句给不出某一年，所以不进底册：

- 后妃：窦皇后（大业中，未几崩，时年四十五）、王皇后与萧淑妃（数日而卒）、何皇后。韦皇后已按景龙四年补入。
- 宗室：李恪（永徽中被诛）、李祐（赐死，句中无年）。
- 文学：李贺（卒，年二十七）、欧阳询（年八十余卒）、元稹（卒，年五十三，句中无年号）。
- 对立：阁罗凤传没有卒年句。岑参、韦应物、张旭、怀素、吴道子不在两唐书列传的人名标题下，这轮没有可引用的卒年。
