# 东汉席位试跑

规则见 pipeline/PLAYBOOK.md。东汉底册这一轮从 42 人增至 48 人。全览能看见新入册的人。叙事章仍是各自点名。

光武到献帝的帝系原来已经在册，这一轮不改他们的生卒。只补皇后纪里能钉住崩年、又是在位皇后或临朝太后的人。阴丽华、邓绥原来已经在册。

100 到 160 的检查线还没有达到。没有为了凑数放宽席位。

马皇后是马援的小女，史失其名。建初元年之后写四年封三舅，其年六月崩，所以记建初四年。

何皇后也史失其名。传从中平六年灵帝崩写到董卓进鸩，后面才写明年，所以卒年记中平六年。她补进「董卓乱政」。

梁妠临朝，兄梁冀鸩杀质帝，她立桓帝。梁女莹是她的妹妹，死于延熹三年，同年梁冀被诛。

## 这一轮不收

皇后纪里只写「在位若干年」或「立七年」，没有年号的，不编。包括和帝阴皇后、安思阎皇后、桓帝邓皇后、灵帝宋皇后、伏皇后。章德窦皇后写永元四年诛窦氏、九年太后崩，九年是否仍是永元，这一轮不把空档补成某一年。

殇帝刘隆的本纪这一轮没有单抽。北乡侯刘懿在位很短，皇后纪没有给他单独的卒年句。
