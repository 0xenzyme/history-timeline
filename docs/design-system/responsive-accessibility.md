# 兰台响应式与无障碍规范

版本：M2 ｜ 日期：2026-11-07 ｜ 上级索引：[DESIGN.md](../../DESIGN.md)

目标为 WCAG 2.2 AA 的可验证设计与实现要求。本文件规定响应式和交互契约，不宣称现有页面已经通过无障碍认证。

## 1. 断点与输入方式

采用 mobile-first CSS，断点由内容需要固定为三档：

| 范围 | 布局 | 典型验证视口 |
| --- | --- | --- |
| 窄屏 `< 768px` | 4 栏、单列、菜单导航、底部面板 | 320×568、390×844 |
| 中屏 `768–1199px` | 8 栏、可折叠侧栏、双列目录 | 768×1024、1024×768 |
| 宽屏 `≥ 1200px` | 12 栏、完整目录侧栏、年表左右面板 | 1440×900、1600×900、1920×1080 |

另以 `@media (pointer: coarse)` 保证触屏目标，以 `@media (hover: none)` 移除 hover 依赖。宽屏触屏设备仍需 44×44px 目标；窄屏外接键盘仍需完整键盘路径。

## 2. 全局移动规则

- viewport 必须允许缩放：`width=device-width, initial-scale=1, viewport-fit=cover`，不设置 `user-scalable=no` 或低 `maximum-scale`。
- 页面padding包含 `env(safe-area-inset-*)`。固定底部控件使用 `max(16px, env(safe-area-inset-bottom))`。
- 除年表内部和明确的横向 tab／朝代带外，320px 宽不产生页面级横向滚动。
- 正文、控件和主要数据不截断。长名称可换两行；长 URL、来源和 id 可断行。
- 200% 文本缩放和 400% 浏览器缩放下，主任务、返回、搜索和错误恢复仍可用。
- 横屏手机不强制旋转提示。年表横屏可以减少顶栏和朝代带高度，但不隐藏选中对象与主操作。

## 3. 导航与通用交互

### 3.1 手机导航

顶栏高 56px，包含品牌、当前栏目、搜索和菜单。点击菜单打开全宽抽屉：

1. 六项导航按固定顺序纵向排列，当前项有文字和标记。
2. 抽屉打开时焦点进入标题或当前项，Tab 不进入背景。
3. Escape、关闭按钮和选择链接关闭抽屉，焦点回菜单按钮。
4. 全站搜索可从顶栏直接打开，不要求先展开菜单。

### 3.2 底部面板

筛选和实体预览使用底部面板，不使用从右侧挤占窄屏的抽屉。

- 收起态露出 64px 标题栏；常规态最大 `60dvh`，展开态最大 `90dvh`。
- 提供明确「展开」「收起」「关闭」按钮。拖动把手只是冗余操作，不是唯一操作。
- 面板有可见标题、关闭按钮和内部滚动区。背景滚动锁定，焦点圈定，关闭后回触发对象。
- 软键盘弹出时使用 `dvh` 和聚焦字段滚动，不让提交／结果按钮永久被键盘遮住。

## 4. 各页面移动结构

### 4.1 首页与目录

- 首页先显示品牌短区、搜索和「开始探索」，再显示四栏目。栏目卡在 390px 可双列，320px 单列。
- 推荐内容使用正常纵向列表；若保留横向列表，显示部分下一张和可访问的滚动按钮，不自动滚动。
- 目录页取消大面积装饰图，保留标题、导语和栏目搜索。
- 筛选收进底部面板，已选条件、结果数、排序、视图切换和重置留在正文。
- 列传默认单列列表，不把小四列网格缩成不可读卡。纪事默认纵向行，不保留桌面六列表格。群像和断代单列。
- 分页优先「上一页／第 N 页／下一页」，完整页码保留在宽屏；页码仍是可分享链接。

### 4.2 人物详情

顺序固定为：

1. 返回与面包屑。
2. 姓名、生卒、身份和「在年表中查看」。
3. 生平简介。
4. 个人经历与时代事件，分区显示。
5. 代表作品。
6. 重要关系与所属群像。
7. 出处。

图片缩为身份区的一部分或隐藏为首字占位。个人经历和关系使用纵向列表，不把桌面三栏挤成横向滚动。

### 4.3 事件详情

顺序为事件头与主操作、概览与事实、正文、结果、事件年表、组成／军事层级、相关人物、相关群像、出处。桌面左页内导航改为「本页内容」锚点下拉，当前章节可见。

`components` 和 `children` 各自保持独立标题。note 和 sources 使用块级展开，不使用只支持 hover 的侧栏提示。

### 4.4 群像与朝代

- tab 允许横向滚动，当前项自动进入可见区域，并提供列表等价入口；方向键不被滚动容器截获。
- 关系图手机默认关系列表，显式提供图／列表切换。
- 系列人物年表使用纵向节点摘要，提供「在完整年表中查看」。
- 朝代首屏只保留名称、区间、可选摘要和主操作；朝代年表用纵向精选节点，不加入完整缩放和平移。

## 5. 移动年表

### 5.1 布局

- 顶栏下为专题／章节工具条，可横向滚动并保留当前专题名称。
- Canvas 占剩余空间，左筛选和右预览默认隐藏。底部工具条包含「分类」「缩小」「缩放值」「放大」「重置」「导出」。
- 朝代带默认收起为当前朝代按钮；展开后是独立可滚动区域，不与 Canvas 同时争抢垂直拖动手势。
- 选中实体后打开底部预览。预览收起时仍显示选中实体名称和「查看详情」入口。

### 5.2 手势与按钮等价

| 任务 | 触屏手势 | 必须同时提供的按钮／键盘 |
| --- | --- | --- |
| 平移 | 单指横向拖动；垂直阈值内不触发 | 向左／向右时间窗按钮；方向键 |
| 缩放 | 双指 pinch，以两指中心对应时间为锚点 | 缩小／放大按钮；`-`／`+` |
| 选择 | 单击节点或线段 | Tab 到可见实体列表，Enter 选中 |
| 预览 | 选中后底部面板 | Enter 打开，Escape 关闭 |
| 重置 | 无强制手势 | 「重置时间窗」按钮；`0` |
| 朝代带 | 横向滚动、点击朝代 | 上一／下一朝代按钮；方向键 |

Canvas 容器按交互方向设置 `touch-action`。单指横向拖动才能平移；垂直页面／面板滚动不能被抢走。双指 pinch 不触发选中或导出。

键盘焦点位于年表时，方向键平移，`Shift+方向键` 按更大步长平移，`-`／`+` 缩放，`0` 重置，Escape 关闭预览。快捷键不能在输入框、select、textarea 或 dialog 内截获。

### 5.3 性能与反馈

- 拖动目标为 60fps，低端设备不得用持续纸张动画或背景模糊消耗帧率。
- 平移／缩放期间可降低装饰细节，但年份、实体名、选中状态和精度标识保持可读。
- 指针结束后更新 URL 的时间窗，拖动过程中不制造大量 history 项。
- 不用自动惯性移动。减少动态效果开启时，所有视窗变化立即完成。

## 6. 键盘、焦点与语义

### 6.1 顺序与焦点

- DOM 顺序与视觉阅读顺序一致。CSS 重排不能造成焦点跳到另一任务。
- 路由进入详情后，焦点到 `<h1 tabindex="-1">`，并更新页面 title；普通同页筛选不重置焦点。
- 打开预览／dialog 时焦点进入，关闭后回触发控件。若触发对象因筛选消失，焦点到结果标题并说明更新。
- 删除、重置、切换视图等操作后焦点位置可预测；不把焦点丢到 `<body>`。
- sticky 顶栏和面板不得遮住焦点，使用 `scroll-padding`／`scroll-margin`。

### 6.2 Canvas 可访问替代

Canvas 不是唯一信息来源。提供「当前时间窗实体」DOM 列表，包含人物／事件名称、年份、精度、类型和选择按钮。列表与 Canvas 使用同一筛选和选中状态。

屏幕阅读器不需逐像素理解关系图。`RelationView` 的列表模式必须包含相同节点、方向、类型和 notes，图只是增强视图。

### 6.3 动态播报

- 筛选结果数使用 `aria-live="polite"`，在用户操作完成后一次播报，不逐帧播报时间窗。
- 路由级加载失败使用聚焦的错误标题；异步操作错误使用克制的 `role="status"` 或 `alert`。
- Canvas 拖动不持续朗读年份。操作结束后可通过状态文本读取当前 from／to。
- skeleton 和装饰纹理对辅助技术隐藏；加载区域提供一条状态文本。

## 7. 对比度、目标和非颜色编码

- 普通文字对比度至少 4.5:1，24px 以上或约 18.66px 粗体的大字至少 3:1。兰台正文仍按 4.5:1 执行。
- 图标、控件边界、选中节点和焦点指示至少 3:1。禁用组件可豁免，但禁用原因必须可读。
- 主文字只用 `ink`，次要文字只用已验证的 `ink-secondary`。新表面、透明叠加和图片背景必须重新计算实际合成色。
- 选中、错误、异说、事件类型、关系方向和加载状态均配文字／图标／形状，不只靠颜色。
- 触屏目标至少 44×44px，目标之间有足够间隔。密集年份轴可缩放，但 DOM 实体列表保持 44px 行目标。

## 8. 动效与减少动态效果

常规反馈为 120–200ms，面板为 200–250ms，只过渡 opacity、color、border 和 transform。没有自动播放、自动横向滚动、循环水墨、星光或首屏编排动画。

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    scroll-behavior: auto !important;
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

减少动态效果还必须在 TypeScript 中关闭惯性、自动平移、平滑缩放和关系图自动布局动画。不能把必要状态反馈隐藏，只移除运动。

## 9. 加载、空、错误与缺失数据

| 状态 | 界面文案与结构 | 恢复动作 |
| --- | --- | --- |
| 首次加载 | 保留页头和页框；目录行、详情标题区、年表坐标使用骨架 | 无需操作；状态文本「正在加载」 |
| 局部失败 | 失败模块显示「暂时无法加载」 | 「重试」只请求该模块 |
| 核心失败 | 页面级「暂时无法加载该人物／事件」 | 「重试」；可返回上级目录 |
| 实体未找到 | 「未找到该人物／事件，链接可能已失效」 | 全站搜索、上级目录 |
| 筛选无结果 | 「没有符合当前条件的结果」，保留条件 | 「重置筛选」 |
| 内容尚未维护 | 「详细生平尚未整理」等具体字段提示 | 无伪造操作 |
| 无直接关联 | 「尚无直接关联事件／关系」，或按规格隐藏可选模块 | 不生成推断推荐 |
| 年份不可定位 | 「缺少可定位的年份」 | 禁用年表主操作 |
| 图片失败 | 姓名首字／类别字标，可选「图片暂不可用」说明 | 正文继续，不阻断 |
| 导出失败 | 非阻断「导出失败，浏览状态未改变」 | 「重试导出」 |

「尚未维护」表示合法缺省，「没有关联」表示数据已加载但无引用，「加载失败」表示请求未完成。三者不能共用一个空白组件。

## 10. M3 响应式与无障碍验收

1. 在 320×568、390×844、768×1024、1440×900 检查唐代年表、李白、安史之乱及往返。记录浏览器、渲染视口和输入方式。
2. 只用键盘完成选择实体、打开预览、进入详情、返回、展开年份说明和打开出处。焦点始终可见，关闭面板后回到触发对象。
3. 用屏幕阅读器检查页面标题、主导航、当前项、实体等价列表、日期精度、事件组成和错误状态。Canvas 不成为唯一入口。
4. 在模拟触屏上分别测试横向拖动、垂直滚动、双指缩放、按钮缩放、底部面板开合和软键盘。模拟测试不能冒充 iOS Safari 真机验证。
5. 检查 200% 文本缩放、400% 浏览器缩放和减少动态效果。无内容遮挡、主操作丢失、自动平移或惯性。
6. 对所有新增表面和状态执行实际对比度测量。纸纹、图片叠加、禁用、错误、焦点和六类事件图形分别检查。
7. 注入核心失败、局部失败、空筛选、无关联、unknown 年份、无图片和非法 id，确认各自文案和恢复路径不同。
