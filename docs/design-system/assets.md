# 兰台素材规则

版本：M2 ｜ 日期：2026-11-07 ｜ 上级索引：[DESIGN.md](../../DESIGN.md)

## 1. 原则与现状

- 图像是阅读辅助，不是人物身份、事件事实或出处的替代。
- 当前没有经确认可投入生产的人物肖像、群像封面或朝代插画许可清单。
- `temp/` 中的生成图、设计脚本和 HTML 内嵌图片只用于视觉参考，不能直接复制到 `public/media/`。
- M2 不批量生成素材。M3 优先使用本地字标、线性和几何占位，使核心路径不依赖图像采购或生成。
- 正式 `MediaRef` 只指向已完成来源、许可和替代文本审查的文件。

## 2. 素材类别与替代

| 类别 | 正式用途 | 缺失／失败替代 | 不得做法 |
| --- | --- | --- | --- |
| 人物肖像 | 身份区、代表成员卡 | display 首字＋纸色圆形／方形底 | 把生成肖像称为真实画像；无图时猜人 |
| 群像封面 | 系列目录和头部 | category 字标＋成员首字组合，不连接关系 | 用合照暗示成员有直接关系 |
| 朝代插画 | 朝代头部装饰 | 朝代名＋区间＋抽象宫格线 | 用插画推导都城、建立者或疆域 |
| 首页水墨 | 品牌氛围 | 深木色纯色＋细线时间坐标 | 让图片承载搜索或关键文字 |
| 事件图片 | 可选目录／头部装饰 | 事件类型形状＋名称 | 把战役想象图当史料；缺图显示空白卡 |
| 纸张纹理 | 低对比背景 | 纯色 `paper` | 纹理影响正文和焦点对比度 |
| 图标 | 操作和类型冗余编码 | 统一线性 SVG；文字标签始终存在 | 使用 emoji、字体图标或来源不明图标包 |

人物姓名、事件名称、朝代、年份和出处始终以 DOM／Canvas 文字存在，不能只存在于图片中。

## 3. 来源与许可

### 3.1 可接受来源

1. 项目自制几何图形、纹理和图标，权利归属清晰。
2. 明确公共领域的古画、书影或档案图像，保存馆方来源、作品信息和公共领域依据。
3. 具有可再使用许可的素材，许可允许本站公开展示、所需裁切和压缩；署名与相同方式共享要求进入清单。
4. 已获书面授权的照片、扫描件或插画，保存授权范围。
5. AI 生成素材只有在生成工具条款、输入素材权利和项目发布政策均允许时使用，并明确标为现代生成插画，不冒充历史图像。

「网上可见」「博物馆网页可下载」「公共领域原作的照片」不自动等于可再使用。摄影、扫描和修复可能有独立权利，必须分别核对。

### 3.2 资产清单

每项生产资产在 `public/media/manifest.json` 登记。清单属于素材许可记录，不是历史事实 canonical 数据。

```json
{
  "src": "/media/people/example.webp",
  "kind": "person",
  "entityId": "example-id",
  "alt": "",
  "credit": "作者或机构、作品名",
  "sourceUrl": "https://example.invalid/source",
  "license": "SPDX 标识或明确许可名称",
  "licenseUrl": "https://example.invalid/license",
  "provenance": "original | public-domain | licensed | commissioned | ai-generated",
  "attributionRequired": true,
  "modifications": "裁切、压缩、调色",
  "reviewStatus": "approved"
}
```

`sourceUrl` 和 `licenseUrl` 必须替换为真实地址，不使用示例值。`reviewStatus` 只有 `approved` 才能被 canonical `MediaRef` 引用。无法确认许可时保留在本地研究区，不进入生产。

### 3.3 历史与生成图像标注

- 历史作品显示作品名、作者（已知时）、年代（有依据时）、收藏／来源机构和许可。
- 现代重绘或 AI 生成插画在信用区标注「现代插画」或「AI 生成插画」，避免被读成史料。
- 肖像的 `alt` 不声称未经证实的外貌身份。装饰肖像在紧邻同名标题时使用空 alt；独立图像使用简短可核查说明。
- 图像信用可以在图下或相邻「素材信息」展开中显示，不能藏在全站笼统声明里。

## 4. 图像制作规范

| 用途 | 显示比例 | 建议源尺寸 | 输出 |
| --- | --- | --- | --- |
| 人物身份 | 4:5，桌面最大 280×350 | 1120×1400 | AVIF＋WebP，400／800px 宽 |
| 人物卡 | 3:4，约 96–144×128–192 | 600×800 | AVIF＋WebP，160／320px 宽 |
| 群像封面 | 16:9 | 1600×900 | AVIF＋WebP，480／960px 宽 |
| 朝代／首页横幅 | 3:1 装饰裁切，另备窄屏构图 | 2400×800 或分层源文件 | AVIF＋WebP，768／1440／2000px 宽 |
| 纸纹 | 无缝平铺 256×256 | 自制灰度／单色 | WebP 或 SVG，透明度 ≤4% |
| 图标 | 24×24 viewBox，实际 20px | 自制 SVG | 单一 stroke 风格，优化路径 |

导出保留原始文件在研究或资产源目录，生产只放优化后文件。位图使用实际宽度的 `srcset`／`sizes`；需要不同裁切时使用 `<picture>`。首屏主图可 eager，其余图像 `loading="lazy"`、`decoding="async"`，并写死宽高避免布局偏移。

文件名使用稳定 kebab-case：`li-bai-portrait-800.webp`。版本更新替换引用，不在文件名中添加无法追踪的随机数。

## 5. 字体策略

### 5.1 首选与回退

正文和控件不下载 Web 字体，使用：

```css
font-family: "PingFang SC", "Microsoft YaHei", "Hiragino Sans GB", "Noto Sans CJK SC", system-ui, sans-serif;
```

标题使用本地别名为 `Lantai Serif` 的字体。实施时优先审查 Noto Serif CJK SC／Source Han Serif SC 的可再分发版本及对应 SIL Open Font License；只有完成许可文件归档和子集检查后才进入生产。回退为：

```css
font-family: "Lantai Serif", "Noto Serif CJK SC", "Songti SC", "SimSun", serif;
```

此规则指定来源策略，不声明字体已经安装或打包。`Lantai Serif` 未提供时直接使用系统宋体，版式必须仍可读。

### 5.2 打包与加载

- 只打包实际使用的字重，首版标题 700，必要时正文宋体 400；不用可变字重伪造多个文件。
- 中文字体按 Unicode range 做静态子集，保留繁简、中文标点、BCE「前」、干支和常见异体字。子集后使用真实历史姓名和出处做缺字检查。
- 字体文件放 `public/fonts/`，许可文本放同目录或 `licenses/fonts/`。本地 `@font-face` 使用 `font-display: swap`。
- 标题字体只预加载首屏实际字重和子集，避免为所有朝代与人物下载全量 CJK 字体。
- 字体加载前后使用尺寸调整后的 fallback，避免布局跳动；不得隐藏标题等待字体。
- 不依赖 Google Fonts 等第三方运行时请求，减少可用性和隐私风险。

## 6. `MediaRef` 与渲染接口

沿用《兰台数据规格》的 `src`、`alt`、`credit`、`license`。实现时：

1. loader 只接收已发布 MediaRef，并在 asset manifest 核对 src、许可和审查状态。
2. `<img>` 写入 alt、宽高和响应式源。装饰图使用 `alt=""` 与空 role，不重复朗读相邻标题。
3. 加载失败监听 `error`，替换为对应字标，不显示破图图标，不删除正文。
4. `credit` 和 `license` 有值时在邻近信用区显示；许可链接只在真实存在时使用。
5. 导出 PNG／SVG 时包含必要的图例和署名。跨域图像未正确同源或 CORS 化前，不进入 Canvas 导出；导出失败不损害浏览状态。

## 7. 预算与验收

- M3 核心路径在无生产人物／事件图片时完整可用。
- 单张人物卡优化图建议不超过 60KB，身份图不超过 180KB，首页首屏图像总预算不超过 350KB；超出需记录原因。
- 图像不引发 CLS；慢网、404、解码失败和不支持 AVIF 时均有回退。
- 检查姓名、出处、异体字和年份在系统字体与打包字体下均无 tofu 缺字。
- 每个生产图像均能追溯到 manifest 的来源、许可、信用和替代文本。缺失任一项不发布该图。
- M3 导出在包含和不包含位图两种情况下验证；不能把设计稿内嵌 base64 直接带入导出。
