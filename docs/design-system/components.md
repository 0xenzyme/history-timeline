# 兰台组件规范

版本：M2 ｜ 日期：2026-11-07 ｜ 上级索引：[DESIGN.md](../../DESIGN.md)

本规范规定 M3–M5 的组件结构、状态和数据表达。组件从 `src/types.ts`、`src/loader.ts` 获取模型，不直接读取 `public/data`，不反向修改事实字段。

## 1. 组件实施约定

### 1.1 语义和链接

- 每页一个 `<main id="main-content">` 和一个 `<h1>`。页头使用 `<header>`，主导航使用 `<nav aria-label="主导航">`。
- 导航用 `<a href>`，动作用 `<button type="button">`。整卡可点击时使用一个主链接，不把交互 chip 包在另一链接内。
- 当前栏目使用 `aria-current="page"`。tab 使用 `tablist/tab/tabpanel` 和方向键；页内锚点导航不伪装成 tab。
- 图标使用统一 20px 线性 SVG 集，`stroke-width: 1.75`。装饰图标 `aria-hidden="true"`，无文字按钮必须有可访问名称。
- 所有数据和正文以 DOM 文字插入或安全渲染；SVG／HTML 必须转义。Canvas 实体在 DOM 中另有等价名称、年份和操作。

### 1.2 通用状态矩阵

| 状态 | 视觉与行为 | 禁止行为 |
| --- | --- | --- |
| default | 纸色表面、墨色文字、1px 结构边框 | 用阴影表示可点击性以外的含义 |
| hover | 主色或背景加深，链接出现下划线 | 只依赖 hover 才显示必要信息 |
| focus-visible | 2px `focus` 外环、2px 偏移；深底使用 `focus-on-dark` | `outline: none` 或只改变颜色 |
| active | 保留边框并显示按压态，100ms 内反馈 | 改变布局尺寸造成跳动 |
| selected | 2px 主色边＋选中图标／文字；表单用 `aria-checked` 或原生状态 | 只用淡色底表示选中 |
| disabled | 原生 `disabled`、可读原因；不可点击 | 只降低 opacity 到难以阅读 |
| loading | 保留原结构和尺寸，使用骨架；操作按钮保留标签并显示「加载中」 | 用默认实体代替数据，或整页只放 spinner |
| empty | 区分无结果、尚未维护、无关联和无法定位 | 连续空卡片、伪造推荐或自动改筛选 |
| error | 指明失败模块、保留其他内容、提供实际重试 | 把网络失败写成「没有内容」 |
| not-found | 页面级说明、搜索与上级目录 | 静默跳到另一实体 |

### 1.3 基础组件

| 组件 | 结构与尺寸 | 必要行为 |
| --- | --- | --- |
| `Button` | 高 44px，主／次／文字三种；图标 20px | 异步时防重复提交；disabled 原因就近显示 |
| `IconButton` | 可视图标 20px，点击区至少 44×44px | `aria-label`、tooltip 可由焦点触发 |
| `TextField` | 可见 `<label>`，高 44px；手机字体 16px | 错误用 `aria-describedby`；placeholder 不代替 label |
| `Select` | 优先原生 `<select>` | 不重造键盘行为；长选项可换行显示于结果摘要 |
| `Chip` | 静态标签或独立链接；高至少 28px，触屏操作 chip 44px | 不用 chip 表示不可点击的筛选按钮 |
| `Card` | 12px 圆角、20px 内边距；数据密集区可用 16px | 可选字段缺失时自然收缩，不留伪占位 |
| `Tabs` | 下划线＋`aria-selected`，高 44px | 方向键切换焦点，Home／End 到首尾；URL 同步 |
| `Breadcrumbs` | `<ol>`，当前项非链接 | 手机保留上级和当前项，不依赖横向滚动才能返回 |
| `Pagination` | `<nav aria-label="分页">`，上一页／页码／下一页 | 页码是链接；越界显示空结果与有效页入口 |
| `Dialog/Sheet` | 优先 `<dialog>`，有标题和关闭按钮 | 焦点圈定、Escape 关闭、关闭后回触发控件；背景不响应 |
| `InlineNotice` | 图标＋标题＋说明＋实际恢复动作 | 普通提示不必 `role=alert`；新错误用克制 live region |
| `Skeleton` | 固定布局的色块，不含虚构文字 | 不对屏幕阅读器逐块播报；区域有加载状态 |

## 2. 导航与页面骨架

### 2.1 `SiteHeader`

内容顺序为品牌链接、副标题、六项导航、全站搜索、辅助设置。新首版只保留有实际功能的设置项；没有行为的月亮、播放和齿轮不显示。

- 桌面当前导航使用金色下划线、浅深木底和 `aria-current`。
- 手机显示品牌、当前栏目、搜索按钮和菜单按钮。菜单内含六项导航；搜索和当前栏目不必开菜单即可使用。
- 页头回到 `/`，不是重置当前年表状态。
- 跳到主内容链接是首个可聚焦元素。

### 2.2 `GlobalSearch`

- 可见标签为「全站搜索」，placeholder 统一「搜索人物、事件、群像、朝代……」。
- 提交到 `/search?q=...&type=all`。建议列表使用 `combobox` 语义；Escape 关闭，不清空已提交查询。
- 结果按人物、事件、群像、朝代分组。精确 name／display／alias 优先，其他规则遵循数据规格，不显示知名度。

### 2.3 `PageHero` 与 `ReturnLink`

- 页头包含面包屑、实体或栏目名、真实摘要、主要标签和一个主操作。
- 「在年表中查看」只在存在有效年份范围时可用；禁用时说明「缺少可定位的年份」。
- `ReturnLink` 文案为「返回」。有应用内来源时执行浏览器返回；无来源时进入本实体上级目录或可定位年表。

## 3. 目录组件

### 3.1 `DirectorySearch`、`FilterPanel`、`ResultToolbar`

目录搜索、筛选和排序分别维护 URL 参数。筛选变化回第 1 页；非法筛选值被忽略并提示，不能产生空白页。

- 桌面筛选栏宽 232–264px，独立滚动只发生在超出视口且底部可见时。
- 手机使用底部面板。正文保留「筛选」按钮、已选条件、真实结果数和「重置」。
- 面板有「查看 N 条结果」和「重置」。单选时期／类型用 radio，多选身份用 checkbox。
- 结果工具条包含结果数、排序和视图切换。排序选项必须来自页面规格，不出现「知名度」。
- 筛选无结果时保留条件与坐标／结果框架，文案为「没有符合当前条件的结果」，提供「重置筛选」。

### 3.2 `PersonCard`

字段顺序为 display、生卒与精度、title、bio 摘要、categories、polity、显式所属群像。没有图片时使用 display 首字占位，不生成肖像。缺 bio 时可隐藏摘要；brief 详情页的缺 bio 提示见人物详情。

整卡主链接进入 `/people/:id`。群像 chip 是独立链接，不能被主链接覆盖。

### 3.3 `EventRow`

桌面列顺序为事件／时间／地点／类型／相关人物／展示优先级。`importance` 只按数据规格用于排序和强调，不渲染虚构的「关键转折」等事实标签。

- 时间使用 `DateRange`；地点缺失隐藏该字段，不生成地图链接。
- `type` 显示受控中文名。`catalogs` 只用于目录筛选，不能显示为两个不同事件。
- 相关人物合并 `people` 与 `commanders`，保留角色；同名 chip 独立进入人物详情。
- 手机默认纵向行，字段顺序为名称、时间、摘要、类型与地点、人物；不保留六列表格横向滚动。

### 3.4 `CollectionCard`、`EraCard`

- Collection 卡片显示 name、summary、category、代表成员和真实 memberCount。`featured` 只改变推荐，不改变成员资格。
- 没有封面时使用类别字标和纸色几何底，不显示虚构人物合照。
- Era 卡片显示 name、from／to 和可选 summary。区间可重叠；不以卡片排列暗示互斥或唯一归属。

## 4. 日期、来源与缺省数据

### 4.1 `DateRange`

统一格式化函数处理所有人物、事件、经历和作品。组件接口至少接收 `year`、`endYear`、对应 `Accuracy` 与 `Note`。

| 数据状态 | 显示 | 时间轴表达 |
| --- | --- | --- |
| `exact` 单年 | `757 年`；BCE 为 `前 479 年` | 实线圆点 |
| `exact` 跨度 | `755—763 年` | 实线段＋端点 |
| `approx` | `约 742 年`；跨度逐端显示 | 空心节点／纹理段；note 可展开 |
| `disputed` | `前 551 年（异说）`，note 完整可读 | 双线或断口节点＋「异说」文字 |
| `unknown` | `生年不详`／`年份待考` | 不生成精确定位点；进入待考组 |
| 一端未知 | `生年不详—757 年` | 已知端精确定位，未知端不补点 |

图形纹理只是冗余编码，文字必须独立成立。note 用相邻的「年份说明」展开，不塞入 title attribute。约略或异说不自动换算成另一确定年。

**真实样本**

- 李白 `birth: 701`、`death: 762` 显示 `701—762 年`。
- 李白经历 `changan-hanlin` 显示 `约 742 年`，并可读「天宝初」note；742 是锚点，不标确切。
- 《蜀道难》无 year，显示作品名称与说明，不显示年份，也不进入有年份的创作轴。
- 孔子 `birthAccuracy: disputed` 显示 `前 551 年（异说）` 和「生年取《史记》前 551 年说」。
- 孟子生卒为 approx 时，两端分别显示「约」，不能只加在整段前而模糊两端状态。

### 4.2 `SourceList`

- 条目保留 `work`、`part`、`note` 原值，按 `classic／modern／database` 分组为「典籍／现代考证／数据库」。
- `database` 旁固定显示「检索线索」，不把它呈现为年份证据。
- 人物总 sources 放在页末；经历、作品和 `partOf` 各自 sources 就近展开。展开前后不重复编造来源。
- 没有 URL 时使用文本，不伪造可点击外链。来源缺失时显示数据提供的实际状态，不补「权威来源」。

## 5. 人物详情组件

### 5.1 `PersonIdentity`

包含 display、name、生卒与 note、title、categories、polity 和可选图片。字号、籍贯没有结构化字段时不出现。`polity` 显示词表名称，但不能从生卒年推导。

主操作位于身份区之后。桌面图片最大 280×360px；手机缩为 96×120px 或姓名占位，图片失败不影响姓名和主按钮。

### 5.2 `ExperienceList` 与公共事件

- 个人经历标题为「个人经历」，公共事件标题为「时代事件」，两个模块始终分开。
- `experiences` 按可定位年份排序；`unknown` 进入「年份待考」分组。每项显示 label、DateRange、可选 place、note 和就近 sources。
- `experience.event` 存在时显示一个「相关公共事件」链接。时间、地点和参与事实读取所引用事件，不复制成第二份。
- `events: []` 时隐藏时代事件模块或显示一次「尚无直接关联事件」，不得按生卒重叠生成。
- 李白的 M1.5 数据没有 `anshi-zhiluan` 反查，因此人物页不得出现设计稿中的安史之乱关联卡。

### 5.3 `WorkList`

作品显示 title、可选 kind、可选 DateRange、note 和 sources。无 year 不推断，无全文链接不显示「阅读全文」，无图片不显示默认书封。

《蜀道难》样本只显示名称、诗歌类别、说明与《新唐书·韦皋传》来源。没有「创作于某年」或「共 120+ 作品」。

### 5.4 `RelationList`

- 每条显示另一人物、关系类型、方向、可选 since、全部非空 notes 和来源 topic 语境。
- `directed` 才使用箭头；无向关系用双向连接线或「与」。
- 同主键不同 note 并列，不随机取一条。冲突关系不得进入 Collection，也不能隐藏冲突。
- 首版只显示当前人物一度关系，不提供「展开二度关系」。同时代、共同事件和同属 Collection 不自动成为关系。

## 6. 事件详情组件

### 6.1 `EventHero` 与 `FactList`

事件头使用 name、DateRange、type、dynasties 和 desc 首段。`type: rebellion` 显示「民变」，不能因 Canvas 图形或设计稿改写为「战争」。

事实区显示时间、可选地点、可选 belligerents／polity。地点完全缺失时在信息区显示「地点未记录」，不生成地图；结果 `result` 缺失时隐藏结果模块。

### 6.2 军事层级与事件组成

两种边不可共用一个「相关战争」列表。

| 数据 | 标题 | 语义和组件 |
| --- | --- | --- |
| `parent` | 「上级军事行动」 | 当前事件的两层军事 parent 链接 |
| 派生 `children` | 「下级军事行动」 | 按 year、importance、id 排列；不由 components 派生 |
| `partOf` | 「所属组合事件」 | 当前事件作为成员指向组合，显示每项 note 与 sources |
| 派生 `components` | 「组成事件」 | 当前组合的成员列表，显示每项 note、事件卡与 sources |

标题下加一次简短说明：军事层级表示战争与其下军事行动；组成表示该事件为何构成组合的一部分。两者都不表示因果。

**安史之乱真实样本**

- 当前 `components` 有香积寺之战和睢阳保卫战，`children` 为空。页面只显示「组成事件」，不伪造「下级军事行动」。
- 香积寺之战的组成说明为唐军反攻并收复长安；睢阳保卫战的组成说明为阻遏叛军南下江淮。说明与各自《旧唐书》《资治通鉴》来源就近显示。
- 成员事件保留 `type: military`、`scale: battle`；安史之乱保留 `type: rebellion`。组成关系不修改这些字段。

### 6.3 `PeopleRoles`

合并 `commanders` 与 `people` 中同一人物，展示 display、角色和 side。commander 角色优先，其他角色保留。人物卡只链接实际 id，不把「唐玄宗」等展示标签当作新实体。

## 7. Collection 与关系组件

### 7.1 `MemberList`、`MemberTimeline`

- 成员以 `members[].order` 排列，显示人物、可选 role、生卒和人物链接。order 是编辑阅读顺序，不是师承、影响或年代。
- `featured` 只用于代表成员，不删除普通成员。
- 年表只画有效年份；unknown 不生成端点。缺少全部有效范围时禁用「在年表中查看」并说明原因。

### 7.2 `RelationView`

- 只渲染 Collection `relations` 显式引用且成功解析的一度边。节点可切换中心，但不展开二度关系。
- 关系图和关系列表使用同一数据。每条边有 source、target、类型、方向、notes 和 topic 来源。
- 手机默认列表，桌面提供「关系图／列表」切换；图形缩放不能成为阅读必要条件。

### 7.3 儒家传承真实样本

- 五名显式成员为孔子、颜回、曾参、孟子、朱熹。成员卡之间不画连续师承箭头。
- 两条可展示关系为 `孔子 → 颜回` 和 `孔子 → 曾参`，类型 `mentor`，notes 分别为「孔门德行科」「孔门弟子」。
- 孟子和朱熹是跨时代代表成员。没有显式边时不连接他们，也不把「孔子—孟子—朱熹」渲染为直接师承链。
- 当前 `eventRecords: []`，不显示相关纪事 tab；没有成员 works 聚合，不显示作品 tab。

## 8. 时间轴组件

### 8.1 `TimelineToolbar`

包含专题／内容线、章节、分类筛选、缩放减／级别／加、重置和导出。控件名称明确为「缩小」「当前缩放」「放大」「重置时间窗」。没有自动播放按钮。

### 8.2 `TimelineCanvas`

- 人物、事件和朝代带共享一个时间刻度。point 事件用节点，span 用线段；未知端点不能补造。
- Canvas 有可读名称和说明。DOM 提供当前可见实体列表或等价搜索结果，使选择、查看详情和时间窗操作不依赖精确指针。
- 单击／Enter 选中实体并打开预览。拖动只平移，双指和按钮只缩放；点击空白取消选中需有明确行为。
- 当前选中对象使用 2–3px 外框和文字状态。预览打开后，焦点进入预览标题；关闭后回到原实体等价控件。
- 筛选为空时保留刻度和「没有符合当前条件的实体」与重置，不保留旧实体制造假结果。
- 加载时使用独立骨架坐标，失败时保留专题导航和重试；不得回退到默认实体。

### 8.3 `EntityPreview` 与 `DynastyBand`

- 预览显示真实核心身份、DateRange、摘要和已有关系／人物摘要。「查看详情」是唯一主操作。
- 桌面右栏宽 320px，最低 288px；手机为底部面板，默认占视口高度不超过 60%，可展开至 90%。
- 朝代带显示区间和视窗框，支持点击、键盘和拖动。手机默认收起为当前朝代按钮，展开后保留可滚动列表。
- PNG／SVG 导出是显式动作，结果包含当前时间窗、筛选、图例和日期精度。导出失败只提示，不改变浏览状态。

## 9. 页面级组合和异常

| 场景 | 组件组合行为 |
| --- | --- |
| brief 人物 | 保留身份和主操作；bio 区显示「详细生平尚未整理」，隐藏 works／experiences，其他模块独立判断 |
| 非法实体 id | 页面级「未找到该人物／事件」、全站搜索和上级目录；不加载另一个 id |
| 局部 JSON 失败 | 失败模块显示「暂时无法加载」和重试；核心实体与已成功模块保留 |
| 核心 JSON 失败 | 页面级错误和重试，保留页头；不显示缓存的无关实体 |
| 图片失败 | 姓名首字或类别字标替代，正文和链接保持原位置 |
| 无有效时间范围 | 禁用年表主操作并说明原因，不生成任意默认时间窗 |
| 无 Collection 事件／作品 | 不显示对应 tab；默认 tab 无效时回 overview 并替换 URL |

这些状态是组件接口的一部分，不得在 M3 之后才补。
