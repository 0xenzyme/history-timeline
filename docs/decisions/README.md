# 设计决策记录

本目录保存从本地 Harness 迁移出来的已接受设计决策。

保留原则：

- 这里只保留可复现的系统设计、契约、验收条件和历史决策。
- Harness 的 status、tasks、goals、packets、intake、mental models、checkpoint 和 run evidence 留在本地 `.harness/`，不进入 Git。
- 运行日志和过程证据不进入版本控制；需要长期保留的结论应提炼到本目录或现有设计文档。

本目录中的 specs 是迁移后的 Git 版本。其余过程文件（status、tasks、goals、packets、intake、mental models）位于本地 `.harness/archive/harness/`，仅作历史备份。
