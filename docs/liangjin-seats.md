# 两晋席位试跑

规则见 pipeline/PLAYBOOK.md。两晋底册现为 50 人（原先 37 人）。全览能看见新入册的人。叙事章仍是各自点名。

这一轮只补东晋本纪里原先缺席、又能钉住卒年的皇帝。西晋四帝原来已经在册。虚岁上推的生年写 approx。两套岁数对不上的，不编生年，也不编一个整数当卒年。

100 到 160 的检查线还没有达到。没有为了凑数放宽席位。

## 这一轮不收

- 司马曜：孝武帝纪写太元二十年九月庚申崩，安帝纪写太元二十一年九月庚申孝武帝崩。两篇纪的年份不同，不选一个卒年。同纪里「崩时年三十五」和「简文崩时年十岁」也差一岁，生年同样不编。
- 宣帝司马懿、景帝司马师、文帝司马昭：庙号在纪里，但不是实际称帝的晋帝。司马懿已在曹魏登记，这一轮不重复拉进两晋。
- 后妃、宰相、八王和已画战事里还缺的主将，下一轮再对列传。

## 还没跑的席位

- 后妃：每位皇帝一位有卒年的皇后或掌权太后。贾南风已经在册。
- 宰相：任上跨过三个年头，或主持过已经画上轴的事，并且本传有卒年。王导、谢安、庾亮已经在册的，不重复造人。
- 八王：轴上只有惠帝、贾后、张华。其余亲王要本传能钉住卒年才收。

没有收的八王：司马亮、司马玮、司马伦、司马冏、司马乂、司马颖、司马颙。玮被斩时年二十一，颖被缢时年二十八，颙死于永嘉初，都没有把年份钉死。

庾皇后死于苏峻之乱后，传里没有写年份。景献羊皇后、宣穆张皇后的崩年在西晋称帝之前或只是追尊一系，这一轮不另占东晋、西晋在位皇帝的后妃席。
